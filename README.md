## 先分清你要的是哪一种“日本服务器”

日本机房能买到的东西大致分三类，价格差着一个数量级，混着比价没有意义。

**独立服务器**：整机独享，E5 系列 CPU、几十 GB 内存、1TB 硬盘起步，带宽常见 50M 到 1Gbps。适合站群、视频分发、需要多 IP 的业务。缺点是开通慢、月付门槛高。

**普通线路日本 VPS**：东京或大阪机房，走当地运营商的常规国际出口。便宜，但晚高峰从大陆访问经常掉速、丢包。日本本土服务商和大部分国际云厂商都属于这一类。

**大陆优化线路 VPS**：在东京机房的基础上，回程单独走电信 CN2、联通 AS9929、移动 CMI/CMIN2 这类精品线路，按访问来源 IP 自动选路。价格比普通 VPS 高，卖点就是晚高峰不掉链子。

GoMami 属于第三类。它的产品线里，Turin 只在香港，Forge 独立服务器也只在香港，日本节点目前只有 Pulse 一条线——三条产品线中定位“性能与价格平衡”的那条，官方给出的适用场景是个人博客、开发测试、中小型 Web 应用、API 与微服务、代理与加速节点。

如果你需要的是整机独享、多 IP 站群，这篇看完可以直接关掉，GoMami 没有对应的日本产品。

## 五个档位分别该给谁

**Nano（$29）是线路验证机。** 2 核 2GB、500GB 流量，跑个探针、监控、轻量代理够用，跑真实站点会很紧。它的价值在于用最低成本确认“你所在的城市、你的运营商，到这条东京线路到底快不快”。

**Pro（$169）是 Windows 起步档。** 8 核 16GB、5TB 流量、3Gbps 端口，需要跑 Windows Server 的话这是最便宜的合规选择。

### 计费周期和年付到底能省多少

GoMami 采用预付费模式，支持月付、季付、半年付、年付四种周期，官方文档的说法是年付相比月付通常能省 15%–20%，各周期具体折扣率并未逐档公布。

拿 Mini 算一下：月付 $49，一年 12 期共 $588。按官方给的 15%–20% 区间推算，年付大致落在 **$470–$500 之间**，折合每月约 $39–$42。这是按官方折扣区间做的算术推算，不是官方报价，实际金额以结算页为准。

年付是否划算，取决于你打算用多久。如果只是验证线路，或者在几个节点之间犹豫，月付更稳妥；24 小时退款只覆盖新购实例的首次购买，一旦转为年付又过了窗口期，就没有免费退路了。

## 官方文档里那些价格页不会告诉你的规则

以下四条都写在 GoMami 官方文档里，但基本不会出现在套餐对比表上，而它们恰恰是最容易踩坑的地方。

**一、流量用超了不停机，但会限速。**

流量只算出站，入站完全不计费，每月额度在计费周期开始重置。额度用完不会断网、也不会按量蹦出超额账单，官方说法是“可能被限速，具体策略取决于产品规格”——具体限到多少，官方没给数字（第三方流传的 20 KB/s 未见官方确认）。中途可以单独买流量包：100GB $6、1TB $60、10TB $600。对预算可控性来说，这比“超量按 GB 计费”友好。

**二、到期当天就停服，没有宽限期。**

这条值得单独强调。续费账单在到期前 7 天自动生成并邮件通知；**到期日当天服务立即暂停**；逾期 5 天终止服务，数据可能不可恢复；逾期 6 天发票自动取消。

换句话说，如果你把站放在这上面又忘了续费，第 5 天之后可能就只剩一份空账套。

**三、600 Gbps DDoS 清洗是付费加购，不是全系自带。**

默认给的是“尽力而为”的基础清洗，自动检测、无需配置。600 Gbps 专业清洗属于付费加购项。另外，当攻击流量影响到同网段其他客户时，IP 会被黑洞 30–60 分钟，自动解除，**人工无法干预**。

这一点和不少第三方文章的写法有出入，那些文章写的是“全系包含 600 Gbps”。按官方文档预期会更稳。

**四、24 小时退款有排除项。**

新购实例 24 小时内可申请全额退款，每人限一次，续费订单不适用。到账时间按支付方式不同：支付宝 1–3 个工作日，加密货币 1–3 个工作日，信用卡 5–10 个工作日。不退款的情况包括：超过 24 小时的订单、因违反条款被终止的服务、续费订单、已使用的账户余额，以及**因 DDoS 攻击被黑洞的 IP**。退款批准后实例和数据立即永久删除，申请前要先备份。

付款方式这块，官方支持信用卡（Stripe 通道，Visa / Mastercard 等）、Stripe Alipay（可以用人民币走支付宝付款）以及 USDT 等加密货币。对国内用户来说，能不能用支付宝这一步不用猜。

这个 24 小时窗口的实际用法很明确：下单当天就跑 ping、traceroute 和一次晚高峰测速，不达标直接退。

## 库存是这条线最不稳定的变量

JPN.Pulse.Mini 是五个档里最容易断货的一个，补货节奏没有公开规律。以下为最近一次观察记录，保留具体时间戳供参考：2026 年 10 月 21 日当天，04:13 补货、05:05 售罄、05:18 补货、06:10 售罄、06:23 补货、07:02 售罄。三次上架三次卖光，最短一次在架约 7 分钟。同一时点，Nano、Air、Pro、Ultra 都显示有货。

## 官方口径的延迟与选点建议

东京节点到中国大陆的典型延迟，官方标注是 **< 50ms**（香港 < 30ms，新加坡 < 70ms），并说明实际延迟受本地 ISP、时段和网络状况影响，建议购买前自测。

官方的选点逻辑也值得抄下来：面向华南用户选香港，面向华北用户日本或香港都行，面向全中国大陆香港综合最优，面向东南亚选新加坡，游戏加速选香港。

这意味着日本节点的定位是“在联通线路上表现不错，同时价格门槛比香港低一截”，重点不在“比香港更快”。如果你是北方联通用户，或者业务本身就落在日本、韩国、东亚，东京这个入口比香港更合适。

## 买之前最后确认三件事

**第一，你要的到底是 VPS 还是独立服务器。** 需要整机独享、多 IP、站群，这篇里的方案都不对口，应该去看独立服务器方向。

**第二，你是不是移动宽带重度上传用户。** 如果是，先买 Nano 测一天上行，别直接上年付。

**第三，你能不能接受“到期即停、五天终止”的规则。** 能接受就按月付或季付起步，跑顺了再考虑年付；不能接受，就把重要数据做异地备份，别把唯一副本放在上面。

按场景给结论：只想验证线路 → Nano（约 $29）；建站、轻量容器、API 后端 → Mini（约 $49）；多站点托管、需要更多核心 → Air（约 $89）；跑 Windows Server → Pro（约 $169）；预算到 $300 以上还在看 VPS → 先重新评估一下是不是该上独立服务器。
